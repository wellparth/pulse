# DailyPulse ⚡

> Unified micro-metrics intelligence platform for indie hackers, solo developers, and small product teams.

## Tech Stack
- **Framework:** Next.js 14+ (App Router)
- **Styling:** Tailwind CSS + Shadcn UI
- **Database & Auth:** Supabase (PostgreSQL)
- **CLI:** Node.js TypeScript (`@dailypulse/cli`)
